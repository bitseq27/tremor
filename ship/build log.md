## M1 — Phase 1: engine foundation, network domain, channels — 2026-10-16 ✅

- Cargo workspace + `Cargo.toml` dependency manifest declared.
- `src/net.rs`: tokio worker thread (isolated runtime, 2 workers) polls the USGS
  `all_hour.geojson` feed every 60 s with a 12 s request timeout; tolerant serde
  structs normalise payload variations (missing mag/place/depth, 2- or 3-coord
  geometries); **magnitude < 4.0 dropped at the network level** (guardrail 1);
  worker-side id dedup before crossing the channel; thread-safe
  `mpsc::sync_channel(64)` into the render thread; link state events LIVE/SIM/OFF.
- Offline guardrail 3: every reqwest error is contained in the worker; after 45 s
  without a successful live fetch a labelled deterministic SIM feed (20 real
  subduction zones, Gutenberg-Richter-ish magnitudes) keeps the globe alive.
  `TREMOR_SIM=1` / `--sim` forces it for demos.
- `src/model.rs`: processing domain — unique-id collection (guardrail 2,
  events reach the GPU queue at most once), ring buffer (512), geo→cartesian
  conversion, wave lifecycle with TTL prune (auto cleanup on dissipation).
- `src/timeutil.rs`: dependency-free UTC civil-time for the HUD epoch readout.
- Validation: `cargo test -j 1` → **20/20 passed** (feed parsing + filtering,
  garbage-payload tolerance, dedup, wave cleanup, geo round-trip, camera math,
  mesh topology, asset integrity, civil-time incl. leap day).

## M3 — Phase 3: pipelines, geometry math, GPU memory layouts — 2026-10-16 ✅

- `src/mesh.rs`: indexed UV-sphere (64×128 for the render, unit normals),
  `#[repr(C)] + bytemuck::Pod` vertex layout matching the GPU alignment rules.
- `src/camera.rs`: orbit camera — drag rotate with inertia, wheel zoom with
  damped distance clamp [1.45, 9.0], look-at + perspective matrices, billboard
  basis, world→pixel projection with hemisphere facing test (occlusion + picking).
- `src/gpu/globe.rs`: uniform buffer (view-proj, cam, light, flags), 1024×512
  equirectangular planet texture built from the embedded land mask (ocean
  banding, phosphor land fill, bright coastline stroke, CRT scan dither),
  storage buffer for up to 96 wave fronts.
- `src/gpu/markers.rs`: instanced billboard epicentres (storage buffer, 512
  instances), magnitude colour + size, depth-tested against the globe.
- `src/gpu/ui.rs`: batched 2D pipeline (solid quads + R8 font atlas sampling)
  that draws every panel/rule/glyph of the HUD in physical pixel space.
- Validation: unit tests (mesh topology/poles, camera projection & occlusion,
  zoom clamps) green; `cargo check` clean.

## M4 — Phase 4: WGSL shaders, wave integration, HUD — 2026-10-16 ✅

- `src/shaders/globe.wgsl`: equirectangular land texture sampled from uv
  derived from the sphere normal; procedural 15° graticule with fwidth-AA and
  brighter equator/prime meridian; **wave integration** — fragment loop over
  the active-quake storage buffer, great-circle angle vs. expanding radius
  `r = speed·t`, gaussian ring profile, quadratic dissipative fade,
  magnitude-coloured (green→yellow→amber→red), white-hot core term;
  fixed-sun diffuse + cyan fresnel rim for the CRT look.
- `src/shaders/markers.wgsl`: instanced billboards, radial core + exponential
  halo, pulsing selection ring; depth-tested so the far hemisphere stays hidden.
- `src/shaders/ui.wgsl` + `src/hud.rs`: pixel-space HUD carrying the reference
  style — top status bar (SYS tag chip, EPOCH UTC, FPS, toggle chips,
  CAM TARGET), link telemetry row, LATEST/SELECTED EVENT panel with recent
  event list, magnitude-distribution bar chart + statistics + data-link
  panel, legend box, bottom key-hint bar, floating magnitude labels.
- Headless validation loop built: `--frames N --shot out.ppm` copies the
  swapchain (COPY_SRC) to a mappable buffer under Xvfb + lavapipe
  (Vulkan/llvmpipe). Iterated visuals from real captures:
  - s1: first light — globe, coastlines, graticule, panels, font all correct.
  - s2: SIM link fix (`--sim` no longer raced by a live poll), marker hover
    offset 1.02 R (equal-depth fail of `CompareFunction::Less`), darker ocean
    + brighter coastline for reference contrast.
  - hero2/hero3: **wave-front bug found by screenshot** — absolute epoch
    seconds in an f32 uniform have ~128 s ulp, so ring time never advanced;
    switched to frame-relative start times; ring width/brightness tuned.
- Guardrails verified in-app: dupes counter, wave prune, pause toggle.
- `cargo test -j 1`: 20/20 green; `cargo check` warning-free.

## M6 — High-res Earth, sensor overlay, in-app SIM toggle — 2026-10-16 ✅

- **High-res planet**: replaced the 720×360 (110m) mask with Natural Earth
  **50m** rasterised at **3600×1800 (10 px/deg**, `tools/gen_assets.py
  --hires`, 810 KB embedded) and raised the startup equirectangular texture
  to **4096×2048**. Coastlines (Red Sea, Persian Gulf, Madagascar, Med
  islands) are now crisp at full-screen zoom; `shots/hi1.png` vs `shots/s1.png`
  shows the delta.
- **Sensor stations**: new `src/sensors.rs` — 38 curated global broadband
  stations (GSN-style IU/II/GT sites, reference lat/lon). Rendered through the
  marker pipeline with a new `kind` flag: `markers.wgsl` draws a crisp
  crosshair + centre pip + thin ring (no halo/pulse) at 1.012 R. Legend gained
  a `+ SENSOR STATION (38)` entry, DATA LINK panel a row, and zooming inside
  2.7 R labels each front-facing station with its code. Unit test validates
  coordinate ranges + unique codes (21/21 tests green).
- **SIMF toggle**: clickable amber `SIMF` chip in the top bar (hit-test rect
  recorded during HUD build, click-vs-drag decided by a 5 px movement
  threshold) plus `F` key and `TREMOR_SIMF=1` env. When ON the app domain
  spawns a sim quake every **10-60 s** (`rng.range(0,50)+10`), each producing
  a wave through the normal ingest path; countdown shown in the telemetry
  row (`SIMF: ON NEXT EVT 02S`). Independent of the network worker's offline
  SIM fallback.
- Wave shader polish: newborn rings no longer saturate to white — amplitude
  ramps in with ring radius (`clamp(0.30 + r, 0, 1)`, energy-spread model).
- Validation: `shots/hi1.png`, `shots/hi2.png` headless captures; 21/21 tests;
  WGSL bool/f32 `max` type error caught and fixed via `select`.

## M7 — Fault lines, epicentre marks, auto-track camera, pen/touch input, launch.bat — 2026-10-16 ✅

- **Fault lines on the globe**: PB2002 plate boundaries (Bird 2003) sourced as
  1443 typed segments from the OpenLyceum/PlateTectonics generated dataset
  (the classic fraxen mirror and peterbird.name are both offline now),
  encoded as 14.4 KB of i16 vectors in `assets/faultlines.i16`
  (`[count][lon0,lat0,lon1,lat1 (deg*100), kind]`). `build_earth_texture`
  stamps them into the 4K planet texture with antimeridian-safe interpolation
  and a plus-shaped 2px stamp: magenta = convergent, yellow = divergent,
  orange = transform. Legend gained three fault rows + mark key.
- **Epicentre marks on the surface**: new storage buffer (128 slots) of
  `EpicGpu {center+magnitude, age/ttl/selected}`; `globe.wgsl` draws a
  surface-attached X + centre pip in the epicentre tangent frame (magnitude
  coloured, bright while its wave lives, dim afterwards) plus a pulsing ring
  around the selected event. Marks rotate/occlude with the globe for free.
- **20 s auto-track**: `OrbitCamera.focus` slews yaw/pitch (shortest-arc,
  exponential ease) onto each newly ingested epicentre - live, sim and SIMF
  events alike - and holds for 20 s; top bar shows
  `CAM TRACK: M4.1 EPICENTRE 08S`; any drag cancels tracking immediately.
- **Pen / touch input fix** (iPad stylus reports): stylus taps and finger
  touches arrive as `WindowEvent::Touch` on Windows (WM_POINTER/WM_TOUCH),
  which the mouse-only path never saw. New unified handler: single
  finger/stylus = drag + tap (same 5 px click-vs-drag threshold, so HUD chips
  and marker picking work by pen), two fingers = pinch zoom.
- **launch.bat**: local Windows build+run script (toolchain check, release
  build no-op-if-fresh, `--sim` passthrough, `rebuild` force flag, error
  pause) - shipped in the zip next to the exe.
- Validation: `shots/fl1.png` (faults + X marks + sensors), `shots/fl3.png`
  (mid-track frame with TRACK chip), chip close-up `shots/fl3_chip.png`;
  22/22 unit tests (new faultline decode test); WGSL scope error (epicentre
  block inserted before `col` declaration) caught by validation and moved.
