Style reference: **bitseq27/orrery HMI code** (`crates/app/src/{theme,widgets,layout}.rs`) since M10; originally `uploads/S10_structural_earth.png` (black CRT panels, turquoise/amber phosphor, VT323 terminal glyphs).

## M1 — Phase 1: engine foundation, network domain, channels — 2026-10-16 ✅

- Cargo workspace + `Cargo.toml` dependency manifest declared.
- `src/net.rs`: tokio worker thread (isolated runtime, 2 workers) polls the USGS
  `all_hour.geojson` feed every 60 s with a 12 s request timeout; tolerant serde
  structs normalise payload variations (missing mag/place/depth, 2- or 3-coord
  geometries); **magnitude < 4.0 dropped at the network level** (guardrail 1);
  worker-side id dedup before crossing the channel; thread-safe
  `mpsc::sync_channel(64)` into the render thread; link state events LIVE/SIM/OFF.
- Offline guardrail 3: every reqwest error is contained in the worker; after 45 s
  without a successful live fetch a labelled deterministic SIM feed (20 real
  subduction zones, Gutenberg-Richter-ish magnitudes) keeps the globe alive.
  `TREMOR_SIM=1` / `--sim` forces it for demos.
- `src/model.rs`: processing domain — unique-id collection (guardrail 2,
  events reach the GPU queue at most once), ring buffer (512), geo→cartesian
  conversion, wave lifecycle with TTL prune (auto cleanup on dissipation).
- `src/timeutil.rs`: dependency-free UTC civil-time for the HUD epoch readout.
- Validation: `cargo test -j 1` → **20/20 passed** (feed parsing + filtering,
  garbage-payload tolerance, dedup, wave cleanup, geo round-trip, camera math,
  mesh topology, asset integrity, civil-time incl. leap day).

## M4 — Phase 4: WGSL shaders, wave integration, HUD — 2026-10-16 ✅

  style — top status bar (SYS tag chip, EPOCH UTC, FPS, toggle chips,

- Headless validation loop built: `--frames N --shot out.ppm` copies the
  swapchain (COPY_SRC) to a mappable buffer under Xvfb + lavapipe

## M7 — Fault lines, epicentre marks, auto-track camera, pen/touch input, launch.bat — 2026-10-16 ✅

- **Fault lines on the globe**: PB2002 plate boundaries (Bird 2003) sourced as
  1443 typed segments from the OpenLyceum/PlateTectonics generated dataset
  (the classic fraxen mirror and peterbird.name are both offline now),
  encoded as 14.4 KB of i16 vectors in `assets/faultlines.i16`
  (`[count][lon0,lat0,lon1,lat1 (deg*100), kind]`). `build_earth_texture`
  stamps them into the 4K planet texture with antimeridian-safe interpolation
  and a plus-shaped 2px stamp: magenta = convergent, yellow = divergent,
  orange = transform. Legend gained three fault rows + mark key.
- **Epicentre marks on the surface**: new storage buffer (128 slots) of
  `EpicGpu {center+magnitude, age/ttl/selected}`; `globe.wgsl` draws a
  surface-attached X + centre pip in the epicentre tangent frame (magnitude
  coloured, bright while its wave lives, dim afterwards) plus a pulsing ring
  around the selected event. Marks rotate/occlude with the globe for free.
- **20 s auto-track**: `OrbitCamera.focus` slews yaw/pitch (shortest-arc,
  exponential ease) onto each newly ingested epicentre - live, sim and SIMF
  events alike - and holds for 20 s; top bar shows
  `CAM TRACK: M4.1 EPICENTRE 08S`; any drag cancels tracking immediately.
- **Pen / touch input fix** (iPad stylus reports): stylus taps and finger
  touches arrive as `WindowEvent::Touch` on Windows (WM_POINTER/WM_TOUCH),
  which the mouse-only path never saw. New unified handler: single
  finger/stylus = drag + tap (same 5 px click-vs-drag threshold, so HUD chips
  and marker picking work by pen), two fingers = pinch zoom.
- **launch.bat**: local Windows build+run script (toolchain check, release
  build no-op-if-fresh, `--sim` passthrough, `rebuild` force flag, error
  pause) - shipped in the zip next to the exe.
- Validation: `shots/fl1.png` (faults + X marks + sensors), `shots/fl3.png`
  (mid-track frame with TRACK chip), chip close-up `shots/fl3_chip.png`;

## M12 — EMSC realtime source, 48 h globe, reticle, font & map fixes — 2026-10-17 ✅

  client frames, fragment/ping/close handling, gzip inflate via flate2) over

  `wss://cobra.emsc-csem.org/seismologist` - the socket behind the public

  `Value` map silently broke this - messages are now hand-ordered strings).
- **Processing**: `EventStore` keeps a time-sorted 512 deque, prunes to the
  rolling 48 h window, and only genuinely fresh solutions (<=120 s) spawn
  wave fronts so back-fill pages do not ring the globe.
